# Sorting Analyzer

A C programming project that compares three sorting algorithms by tracking their comparisons, swaps, and shifts.

## Sorting Algorithms

- Bubble Sort
- Selection Sort
- Insertion Sort

## Features

- Sorts an array using three different algorithms
- Counts comparisons
- Counts swaps in Bubble Sort
- Counts swaps in Selection Sort
- Counts shifts in Insertion Sort
- Displays the sorted array for each algorithm

## Concepts Used

- C programming
- Functions
- Arrays
- Loops
- Conditional statements
- Pointers
- Sorting algorithms

## How It Works

The program creates copies of the original array so that each sorting algorithm works on the same input.

It then records the operations performed by each algorithm and displays the results.
