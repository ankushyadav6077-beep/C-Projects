# Student Result Analyzer

A C programming project that analyzes a student's marks and generates a simple result summary.

## Features

- Accepts student name
- Accepts marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Finds highest marks
- Finds lowest marks
- Counts passed and failed subjects
- Calculates grade based on percentage

## Concepts Used

- C programming
- Functions
- Arrays
- Loops
- Conditional statements
- Pointers
- `fgets()` and `scanf()`

## Grade System

| Percentage | Grade |
|------------|-------|
| 90% and above | A |
| 75% - 89% | B |
| 60% - 74% | C |
| 40% - 59% | D |
| Below 40% | F |
